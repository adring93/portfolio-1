Semester Project 2

AuctionHub is an auction marketplace project built with HTML, CSS and JavaScript, using the Noroff Auction API. For Portfolio 2, I improved the visual presentation, listing cards and overall marketplace feel.

Live Site GitHub README

Project overview

AuctionHub is an auction website where users can browse listings, view individual auctions, register, log in, create listings and interact with auction content. The project was built using JavaScript and the Noroff Auction API.

What I improved

For Portfolio 2, I focused on making the homepage and listing cards feel more professional. I improved spacing, card structure, visual hierarchy and the general marketplace presentation.

Technical improvements

I worked on making the listing cards clearer by showing important auction information such as bids, current bid and time left in a more structured way. I also improved the visual consistency across the homepage.

Reflection

This project taught me that presentation matters a lot in marketplace design. Even when the functionality works, the user needs to quickly understand what is for sale, how active the auction is and why they should click into a listing.
