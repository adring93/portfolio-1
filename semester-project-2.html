Semester Project 2

AuctionHub is a vanilla JavaScript auction marketplace built with the Noroff Auction House API, improved for Portfolio 2 with stronger listing cards and a more polished marketplace presentation.

Live Site GitHub README

Project overview

AuctionHub is a front-end auction web application built with HTML, CSS and vanilla JavaScript. Users can browse live auctions, filter and search listings, view individual auction pages, register, log in, create listings, place bids and manage their profile.

What I improved

For Portfolio 2, I improved the auction listing cards and the overall marketplace presentation. The cards now have a cleaner image area, stronger hover states, a clearer bid badge and improved layout for current bid and time left.

UX decision

I first tested adding a Featured Auctions section, but after reviewing it I felt it pushed the live listings too far down and made the browsing experience worse. I changed direction and improved the existing listing cards instead.

Reflection

This project made me think more about marketplace UX. For an auction site, quick browsing and product discovery are important, so the best improvement was not adding more content above the listings, but making the existing listings easier and more enjoyable to scan.
